# Ejercicios JDBC - Acceso a datos (2 DAM)

Práctica de los seis ejercicios JDBC: Tienda, Instituto, Deportes, América, Matrícula y Comercio.

Cada carpeta contiene dos archivos Java: `ConexionDB.java` y la clase principal del ejercicio.
La conexión utiliza MySQL local, usuario `root` y contraseña `root`, igual que en el proyecto entregado.
Si se usa otra configuración de MySQL, hay que adaptar `ConexionDB.java`.

Los scripts de la carpeta `scripts_sql` permiten crear las bases de datos de prueba.

Ejercicio 6: se incluyen las opciones de crear y consultar pedidos tal como figuran en los archivos del alumno. Las operaciones de modificación y eliminación de pedidos no están implementadas en estos archivos.

Los seis proyectos Java compilan con JDBC y MySQL Connector/J añadido como biblioteca de IntelliJ.
